# InkSight 功能清单 (Features)

InkSight 是一款集深度阅读、可视化笔记与知识管理于一体的本地优先应用，支持 Web 与 Electron 桌面运行方式。

## 核心功能 (Core Features)

### 1. 多格式文档阅读 (Multi-format Reader)

- **PDF 阅读**：基于 PDF.js 渲染，支持缩放、翻页、文本选择和复制。
- **EPUB 阅读**：基于 epub.js，支持流式排版与章节跳转；文档内嵌脚本默认禁用。
- **纯文本与 Markdown**：支持 `.txt` 和 `.md` 文件，并渲染 Markdown 内容。
- **阅读标注**：支持矩形选择、椭圆选择、自由荧光笔以及标注列表。
- **双向溯源**：由文档创建的卡片可跳回对应文档位置；文档暂未加载时会显示恢复状态。

### 2. 可视化笔记与知识图谱 (Visual Notes and Knowledge Graph)

- **拖拽创建卡片**：将选中文本或截图直接拖入画布。
- **Drawnix 无限画布**：支持自由绘图、文本、连接线和思维导图节点。
- **组织布局**：支持按来源、时间或宽松模式重新组织画布内容。
- **图谱视图**：可从标注展开关联节点；单击选中后进行滚动、标记和节点操作，未选中时支持整卡拖拽、延迟完整标题预览与双击放大。
- **可选 AI 问答**：配置第三方 AI 服务后，可在图谱上下文中进行流式问答；放大气泡可分别编辑显示标题与完整问题并重新生成，失败时保留原回答。相关提示词和上下文会发送给所选服务商。

### 3. 项目与持久化 (Projects and Persistence)

- **本地优先**：浏览器版使用 IndexedDB/LocalStorage，并允许选择长期记住或仅当前页面会话使用 API Key；桌面版还会使用本机运行时目录、操作系统安全存储和用户选择的项目目录。
- **自动保存与恢复**：保存阅读进度、标注、卡片、画布和图谱状态，并提供历史恢复能力。
- **项目目录工作流**：可打开或导出完整项目目录，包含项目数据、文档和资源。
- **兼容快照**：历史记录与恢复流程继续使用 `.inksight` 快照文件。
- **内容导出**：支持导出大纲、引用和 Markdown 笔记包。

### 4. 界面与可访问性 (Interface and Accessibility)

- **工作区预设**：提供阅读、摘录和图谱三种工作模式。
- **响应式布局**：适配桌面、平板和手机宽度，并提供移动端工具栏。
- **多主题**：支持默认、彩色、柔和、复古、暗夜和星空主题。
- **多语言**：应用外壳及主要工作流支持简体中文和 English，并可在设置中即时切换。
- **键盘与辅助技术**：关键状态反馈、焦点处理和控件名称覆盖主要交互流程。

## 隐私边界 (Privacy Boundary)

文档和项目默认保存在本机。只有在用户主动配置并调用 AI 功能时，提示词、所选内容或图谱上下文以及鉴权信息才会发送到所配置的第三方服务。详见 [隐私说明](../PRIVACY.md)。
